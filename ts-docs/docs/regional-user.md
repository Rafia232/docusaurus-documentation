# Regional User Guide

This page provides the regional-user guidance for the MoH Helpdesk platform.

Regional users review tickets escalated from facilities, monitor service performance in their assigned area, and coordinate support actions when needed.

## Key responsibilities

- Review and triage tickets assigned to the region
- Escalate issues to national or technical teams when required
- Monitor service quality and recurring issues
- Support facility-level resolution where appropriate
