# National User Guide

This page provides the national-user guidance for the MoH Helpdesk platform.

National users oversee broader platform performance, review regional escalations, and coordinate cross-region support activities.

## Key responsibilities

- Review escalations from regional users
- Monitor national-level reporting and trends
- Coordinate high-priority or cross-region incidents
- Support policy and operational oversight across the platform
